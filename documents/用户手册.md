# 白板 WhiteBoard · 用户手册（S1 版）

> 适用版本：S1（`1.5.0`）　最后更新：2026-09-12
> 面向读者：**使用者（老师）** 与 **部署者（信息老师 / 网管）**。
> 技术选型与架构说明见 `白板开发总路线.md`；本手册只讲"怎么用"。

---

## 一、它是什么

一个给课堂用的**手写白板**：用笔或手指在屏幕上写字、画几何图形、擦改、写文字、翻页，
存成一个画板文件（`.wb`），也可以导出成 PNG 图片交给学生。

三条与"能不能在学校电脑上跑起来"有关的硬保证：

| 保证 | 具体含义 |
|---|---|
| **免环境部署** | 整个程序就是一个文件夹，**复制过去双击就能跑**。不装运行时、不要管理员权限、不联网、**不依赖 VC++ 可再发行组件** |
| **不写注册表** | 不改系统设置、不留注册表垃圾；**删掉文件夹就等于卸载干净** |
| **数据自包含** | 程序自己的数据（主题、自动保存、最近文件、默认文档与导出目录）**全部在程序文件夹的 `data\` 里**；你显式"保存到桌面/U 盘"的画板当然在你选的位置 |

支持的触摸/手写输入：**电磁笔 / 电容笔、手指、鼠标**三种都能用，优先级为**笔 &gt; 手指 &gt; 鼠标**。

## 二、安装与启动

1. 拿到 `selfcontained` 文件夹（约 140 MB）。
2. **把整个文件夹**复制到目标电脑任意位置（桌面、D 盘、U 盘都行）。
   - ⚠️ 不要只复制 `WhiteBoard.exe` 一个文件——它旁边还有运行时与主题文件，缺一不可。
3. 双击文件夹里的 **`WhiteBoard.exe`**。
4. 想确认"在这台电脑上没问题"，双击 **`验证.cmd`**：黑窗口会打印 **9 行 PASS**，最后一行是"结果：全部通过"。
   只要看到这个，就说明数据目录、编码、主题、依赖都正常。

> **程序文件夹必须可写**。若放在只读位置（如某些受保护的共享目录），
> 程序会进入只读模式：**自动保存会关闭**，底部状态栏会给出红色提示。
> 这时把整个文件夹复制到可写位置即可。

## 四、基本操作

### 4.1 写字（画笔）

点工具栏「画笔」（或按 `1`），按住笔/手指/鼠标在画布上拖。
**书写过程中显示的是实时预览**，抬笔后笔迹才落进文档——预览与最终笔迹是同一套几何，
所以抬笔瞬间**不会跳变**（这正是旧方案让人看着别扭的地方）。

- 笔宽三档：**细 3 / 中 6 / 粗 10**（世界单位，随缩放等比放大）。
- **下笔即固定**：笔迹按采样点直接落墨，**已经画出来的部分不会再被"优化"移动**（ADR-20）。
  想让线条更圆润（代价是已画部分会随新笔尖轻微移动），可以用 `WhiteBoard.exe --smooth` 启动对比。
- 颜色：点工具栏色板（色板来自 `data\theme\color.txt`）。

### 4.2 画图形

「直线」「矩形」「椭圆」都是**拖动绘制**：按下 → 拖 → 松开。拖动过程中会显示橡皮筋预览。
- 位移太短（小于约 2 个世界单位）视为误触，不会生成图形。
- 矩形/椭圆是**空心描边**，不是填充块。

### 4.3 擦除（橡皮）

「橡皮」（`5`）按住拖动即可擦。要点：

- 擦除是**把笔迹挖掉一块**，不是把一笔切成好几段——擦过之后**仍然是一个对象**，
  可以整体撤销、整体移动、整体删除。
- 擦到一点都不剩时该对象会被**自动删除**；撤销可以把它连同原来的形状一起恢复。
- **橡皮直径**：手指 60 px、笔 24 px；**手掌按在屏上会当成大号橡皮**（按接触面积放大）。
- **文字不参与擦除**（见 4.5），橡皮划过文字不会破坏它。

### 4.4 选择与修改

「选择」（`6` 或 `S`）：

| 想做什么 | 怎么做 |
|---|---|
| 选中一个对象 | 点它一下（**点到的永远是你看到的最上面那层**） |
| 选多个 | 点工具栏「多选」后依次点；或按住 Ctrl/Shift 点 |
| 框选一片 | 在空白处拖一个方框（碰到即选中） |
| 圈选（触屏更好按） | 点工具栏「圈选」后沿轨迹围一圈 |
| 全选本页 | 「全选」或 `Ctrl+A` |
| 移动 | 拖动**已选中**的对象；多个选中会一起移动 |
| 删除 | `Del` / `Backspace`，或「删除」按钮 |
| 调图层 | 「置顶」/「置底」 |
| 克隆一份 | 「克隆」——在原地偏移一点复制，并把选中切到副本上 |
| 改笔迹粗细 | 选中笔迹 → 选好笔宽 → 点「用当前笔宽」（可撤销） |
| 取消选择 | 点空白处，或 `Esc` |

- 手抖（位移小于 4 像素）不会被当成拖动，所以"想点选却不小心移了对象"不会发生。
- **被橡皮擦掉的部分点不中**——与你在屏幕上看到的完全一致。
- 移动/删除/置顶都是**可撤销**的（`Ctrl+Z`）。

### 4.5 写文字

「文本」（`7` 或 `T`），在画布上点一下即可输入：

- 使用的是**真正的输入框**，因此**中文输入法（候选窗、联想）天然可用**。
- `Enter` **换行**（可以写多行标题/条目）；`Ctrl+Enter` **提交**；
  点画布别处或切换工具也会自动提交；`Esc` 取消本次输入。
- 工具栏「字号」三档：**小 24 / 中 36 / 大 56**（世界单位，随缩放等比放大，放到 50 倍也不糊）。
- 点工具栏「粗体」切换粗体；**对着已选中的文字**点它可以直接改那段文字的样式（可撤销）。
- 用文本工具**点已有文字**是**修改那一段**，不会在旁边叠一段新的。
- **文字不参与橡皮擦除**（这是设计要求：文字被啃掉半个字没有意义）。
  要删文字：用「选择」选中它，按 `Del`。

### 4.6 缩放与平移

| 操作 | 效果 |
|---|---|
| 滚轮 | **以光标为中心**缩放 |
| 鼠标中键拖动 | 平移 |
| 两指捏合 / 拖动 | 缩放与平移（**缩放中心跟随两指中点**） |
| 「缩小 / 放大 / 100%」 | 按钮缩放，`Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| `F11` / `Esc` | 进入 / 退出全屏 |

缩放到 **50 倍仍是矢量重绘**（不是把图片放大），所以线条不会变成马赛克。

## 五、多页面

左侧是**页面目录**，每页一张缩略图（按内容裁剪，一眼看出哪页写了什么），当前页用黄框标出。

| 操作 | 说明 |
|---|---|
| 切页 | 点缩略图，或「上一页 / 下一页」，或 `PageUp` / `PageDown` |
| 新建页 | 加一张空白页并自动切过去 |
| 复制页 | 把当前页整页复制一份（**连擦除痕迹与缩放位置都一起复制**） |
| 删除页 | 会先确认；只剩一页时按钮变灰（**画板至少要有一页**） |
| 撤销页面操作 | 做完上面任一操作后，状态栏右侧出现「撤销页面操作」，点它即可退掉刚才那一步 |
| **跨页搬运对象** | 用选择工具选中对象后，把它**拖到左侧某一页的缩略图上**；或点「移到…」选目标页 |
| **调整页序** | 在左侧目录里**上下拖动**某一页的缩略图到目标位置；做完可用状态栏「撤销页面操作」还原 |

- 对象搬到另一页后**保留原来的位置**（两页共用同一个坐标系），不会"跑位"。
- **每页有独立的撤销历史**：在 A 页按 `Ctrl+Z` 只会撤销 A 页上的操作，不会撤销别的页。
  切页本身不进入撤销历史。
- 页面操作（新建/复制/删除/追加导入）**不走 `Ctrl+Z`**，用状态栏的「撤销页面操作」按钮——
  这样才能保证 `Ctrl+Z` 永远是"撤销当前页上的内容改动"。

## 六、文件：保存、打开、导出

### 6.1 保存与打开

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 新建 | `Ctrl+N` | 空白画板 |
| 打开 | `Ctrl+O` | 打开 `.wb`；打不开时会给出**中文原因**（不是英文报错） |
| 保存 | `Ctrl+S` | 首次保存会问位置；默认在 `data\documents\` |
| 另存为 | `Ctrl+Shift+S` | 存到别处 |
| 最近文件 | 「最近 ▾」 | 列出最近打开的画板（名称 + 页数 + 对象数 + 时间），点一条即打开 |

### 6.2 追加导入

「追加导入」把**另一份 `.wb` 的所有页**加到当前文档末尾（合并两个老师的素材）。
- 导入的页会排在最后，并自动切到第一张导入页；
- **会重新分配内部编号**，因此不会与当前文档里的对象冲突；
- 导入后可用状态栏「撤销页面操作」整体退掉。

### 6.3 导出 PNG

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 导出当前页 | `Ctrl+E` | 按**内容裁剪**、2 倍分辨率（打印/投影都够清晰） |
| 导出全部页 | `Ctrl+Shift+E` | 每页一张，命名形如 `画板名-第01页.png` |

导出默认目录：`data\export\画板名\`。导出图与屏幕看到的一致——
**屏幕上擦掉的地方，导出图里也一定是空的**。

### 6.4 自动保存与崩溃恢复

- 有未保存改动时，程序会在你**停笔约 25 秒后**自动存一版；如果你连续书写不停，**最多 90 秒**也会存一版。
  （自动保存放在 `data\autosave\`，不占用你的画板文件。）
- 万一程序崩溃 / 断电：**下次启动会问你"发现上次未保存的内容，是否恢复"**。选「是」内容就回来了。
- 正常保存过之后，自动保存会被自动清理，不会反复打扰你。

### 6.5 数据放在哪里 / 怎么卸载

```
WhiteBoard\                      ← 整个文件夹，复制即安装
├─ WhiteBoard.exe
├─ *.dll                         ← .NET 运行时（自带，不需要系统装）
├─ 快捷键说明.txt                 ← 本手册的快捷键部分（程序内「快捷键」按钮打开）
├─ 验证.cmd                       ← 双击做 9 项自检
└─ data\                          ← 程序自己的数据（全部在这里）
   ├─ theme\color.txt             ← 主题色（可自己改）
   ├─ documents\                  ← 默认保存位置
   ├─ export\                     ← 默认导出位置
   ├─ autosave\                   ← 自动保存
   └─ recent.json                 ← 最近文件列表
```

**卸载**：删掉整个 `WhiteBoard` 文件夹即可。程序不写注册表，也不往系统目录写任何东西。
（你自己的画板文件若保存在别处，需要自己留着。）

## 七、自定义主题色

编辑 `data\theme\color.txt`（JSON），例如：

```json
{
  "id": "classroom",
  "name": "我的课堂",
  "background": "#203040",
  "colors": [
    { "name": "白", "value": "#F5F5F0" },
    { "name": "黄", "value": "#EED858" }
  ]
}
```

- 改完**重启程序**生效；工具栏色板与画布背景都会跟着变。
- 底部状态栏会显示当前主题来源：**用户文件** 还是 **内置默认**。
- 文件写坏了也不怕：程序会**回退到内置默认**并在状态栏给出黄色提示，不会打不开。

## 九、常见问题

| 现象 | 原因与处理 |
|---|---|
| 底部红字"程序文件夹不可写" | 程序放在只读位置。把整个文件夹复制到可写位置（桌面/D 盘）。此时**自动保存关闭**，请手动 `Ctrl+S` |
| 打开画板提示"这不是有效的 .wb 画板文件" | 文件损坏或被改过后缀。用 `Ctrl+Z` 之外的途径找找备份，或从 `data\autosave\` 恢复 |
| 提示"跳过 N 个无法识别的图元" | 该文件由**更新版本**的程序创建、含本版本不认识的图元。能识别的部分会照常打开（这是刻意的向前兼容策略） |
| 提示"画板文件由更新版本的程序创建" | 格式版本过高，请升级程序后再打开（不硬读，避免数据错乱） |
| 写字时有明显延迟 | 先确认是否在"极高缩放下 + 极多对象"的场景；一页建议不超过 500 个对象 |
| 手指画不准 | 用笔。笔在感应范围内时手指触摸会被忽略（防误触），这是有意设计 |
| 想缩放但一按就画了一笔 | 落笔后 **150 毫秒内**第二指落下才会被判为手势；想要稳定缩放，可以先两指同时落下再动 |
| 文字改不了 / 点不动 | 用「文本」工具点**文字框内部**即可编辑；要移动/删除请用「选择」工具 |

## 十、已知限制（S1 的范围）

S1 的目标是"**能上课的稳定白板**"，以下**暂不支持**（分别在 S2/S3/S4 规划）：

- 图形的**旋转**与手柄缩放（可以整体拖动移动）；文本**不支持旋转**；
- 图片、数学公式、化学式、几何辅助线等复杂对象；
- 右键菜单 / 长按菜单；
- 一键打包整本画板（`.wb` 里已含所有页，无需额外打包）；
- 插件生态（第三方扩展）；
- 跨显示器 DPI 变化（S1 只保证**单显示器正确**）。

## 十一、给部署者（信息老师 / 网管）

| 事项 | 做法 |
|---|---|
| 批量部署 | 直接把 `selfcontained` 文件夹复制到各机（可放共享盘让老师自己拷）。**不需要安装程序、不需要管理员** |
| 快速体检 | 目标机双击 `验证.cmd`，看到 9 行 PASS 即可；或命令行 `WhiteBoard.exe --self-test --report 报告.txt` |
| 集中放课件 | 把 `.wb` 放在共享目录，老师用「打开 / 最近文件」访问；注意**打开时别让多台机器同时写同一个文件** |
| 统一主题色 | 把统一的 `color.txt` 放到各机 `data\theme\` 下 |
| 合规审计 | 程序不写注册表、不在程序目录外写文件（用户显式保存/导出除外）。可用 Process Monitor 过滤 `Process Name is WhiteBoard.exe` 核对：`RegSetValue/RegCreateKey` 应为 **0 条** |
| 干净环境验证 | 在 Windows 沙箱或全新虚拟机里零拷贝运行一次 `验证.cmd`，确认不依赖任何预装组件 |
| 系统要求 | Windows 10 与 Windows 11（同一份产物）；.NET 运行时**已随包自带** |
| 备份 | 把整个 `selfcontained` 文件夹复制一份即可（程序不写注册表、不写系统目录，复制即完整备份） |

### 命令行入口一览

| 命令 | 用途 |
|---|---|
| `WhiteBoard.exe` | 正常启动 |
| `WhiteBoard.exe --demo` | 启动时载入示例画板（演示/培训用） |
| `WhiteBoard.exe --self-test [--report <txt>]` | 9 项免环境自检，退出码 0 = 通过 |
| `WhiteBoard.exe --render-smoke [--out <png>] [--report <txt>]` | 渲染链路自检（14 项，含写出 PNG；不指定 `--out` 时为 13 项），产出成图 |
| `WhiteBoard.exe --file-smoke [--report <txt>]` | 文件层 + 页面 + 文本自检（21 项），含"存读逐像素一致" |
| `WhiteBoard.exe --size 1000x700` | 以指定窗口尺寸启动（排查窄屏布局） |
| `powershell -File scripts\ui-tools-test.ps1 -ExePath <exe> [-OutDir <目录>]` | **画布交互自检**：真的用鼠标画一笔、用键盘切工具，逐个确认画笔/矩形/椭圆/橡皮/文本都能工作（9 项） |
