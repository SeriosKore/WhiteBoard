## 这一版是什么

一个**免环境部署**的课堂手写白板：复制文件夹双击即用，不装运行时、不要管理员、不写注册表、
数据全部在自己文件夹里。S1 的功能面已经完整——**能写、能画、能擦、能选、能改、能写字、能翻页、能存能开能导出**。

---

## 本版内容

### 书写与绘图
- 笔 / 手指 / 鼠标三路输入统一处理（笔 > 手指 > 鼠标优先级），压感变宽
- **下笔即固定**：已画部分不会被"平滑优化"移动（ADR-20）。想对比旧手感可用 `--smooth` 启动
- 直线 / 矩形 / 椭圆：拖动绘制 + 橡皮筋预览，空心描边
- 橡皮：按覆盖面积**挖掉一块**（不是把一笔切成碎片）；擦空即删；手掌自动当大号橡皮

### 选择与编辑
- 点选（取最上层）/ 框选 / 圈选 / 多选（`Ctrl+A`）
- 拖动移动（多个对象一起移动）、`Del` 删除、置顶 / 置底、**克隆**、把笔宽应用到选中的笔迹
- 手抖（<4 px）不会被当成拖动；被擦掉的部分点不中（与看到的完全一致）

### 文本
- 就地叠加真 `TextBox` → **中文输入法（候选窗、联想）天然可用**
- 字号三档（24 / 36 / 56 世界单位）+ 粗体 + 多行；点已有文字即**修改那一段**
- 文本**不参与橡皮擦除**（要删文字用选择 + `Del`）

### 多页面
- 左侧页面目录 + **按内容裁剪的缩略图**（当前页黄框）
- 翻页（点缩略图 / 按钮 / `PageUp`·`PageDown`）、新建 / 复制 / 删除页
- **跨页搬运对象**：把选中的对象拖到缩略图上，或点「移到…」
- **拖动缩略图调整页序**
- 每页独立撤销栈：`Ctrl+Z` 只撤销当前页的内容改动

### 文件
- `.wb` 包（ZIP + JSON、`schemaVersion`、**原子写**：断电最坏只留临时文件，绝不写坏老文件）
- 保存 / 另存为 / 打开 / 最近文件；损坏文件给**中文可读原因**；版本过高明确拒绝
- **自动保存与崩溃恢复**：停笔约 25 秒落盘、连续书写最多 90 秒；重启时询问是否恢复
- PNG 导出（当前页 `Ctrl+E` / 全部页 `Ctrl+Shift+E`，2 倍分辨率、按内容裁剪）
- **追加导入**：把另一份 `.wb` 的所有页并到当前文档末尾

### 视图
- 滚轮**以光标为锚点**缩放、中键拖动平移、双指捏合/平移（缩放中心跟随两指中点）
- 50 倍**矢量重绘**（不是把位图放大）；全屏 `F11`

## 验证证据

全部可复现：克隆仓库后跑 `scripts\verify.ps1`（**21 项全绿、退出码 0**）。

| 项目 | 结果 |
|---|---|
| 单元测试 | **225 项**（Core 117 + Rendering 108） |
| 免环境自检 | 9 项 PASS（数据目录 / 编码往返 / ANSI 回退 / 路径穿越 / 主题 / 无第三方原生库） |
| 渲染链路自检 | 14 项 PASS（含"椭圆真的是椭圆""擦除处确实缺像素""文本位置正确"） |
| 文件层+页面+文本自检 | 21 项 PASS，其中 **存读前后渲染逐像素一致：0 / 1024000** |
| 画布交互自检（真鼠标真键盘） | 9 项 PASS（画笔 / 矩形 / 椭圆 / 橡皮 / 文本 / Esc / `Ctrl+Z`） |
| 拖动交互自检（真鼠标） | 6 项 PASS（拖对象 / 中键平移 / 跨页搬运 / 页序拖拽） |
| PE 依赖审计 | 无未随包携带的 VC++ 运行时；发布目录无系统版可再发行组件 DLL |
| 自包含发布 | 139.7 MB，复制即用 |

**开发过程中修掉的 12 个真实缺陷**（每个都有根因与量化数据）见 `documents\S1实现进度.md` §四，
其中值得一提的三个：

- **水平笔迹被视口裁剪整条丢掉**：采样点包围盒高度为 0 且未计笔宽 → 平移后笔迹凭空消失
- **拖动移动后撤销失效**：实时改坐标导致撤销命令把"终点"当成起点
- **文本编辑浮层吃掉全部指针输入**：`Background="Transparent"` 让浮层参与命中测试 → 所有工具都画不出东西

## 安装 / 运行

1. 下载本 Release 的 `WhiteBoard_*.zip`（约 62 MB）
2. 解压出整个文件夹（**不要只复制 exe**）
3. 双击 `publish\selfcontained\WhiteBoard.exe`

验证这台电脑能不能跑：双击同目录的 `验证.cmd`，看到 **9 行 PASS** 即可。

**环境要求**：Windows 10 / 11（同一份产物）。**不需要** .NET 运行时、不需要 VC++ 可再发行组件、
不需要管理员权限、不需要联网。

## 已知限制

- 图形与文本**不支持旋转**；图形不支持手柄缩放（可整体移动）
- 没有图片、数学公式、化学式、右键菜单
- 跨显示器 DPI 变化未处理（只保证单显示器正确）；4K 只保证不错位
- 插件生态（S3）、i18n 与签名部署（S4）尚未开始
