## 五、关键技术要点

### 5.1 布尔差集的坐标往返（最容易出错的点）

```
对象局部路径
  → 乘以对象变换矩阵 → 世界坐标路径
  → 与"擦除圆合并路径"执行 Geometry.Combine(Exclude)
  → 结果反变换回局部坐标
  → 转为 PolygonObject（保留外轮廓；孔洞需单独处理）
  → 结果为空 → 删除对象
```
**必须处理**：矩阵不可逆（极端缩放）、差集结果自交、多段分离路径（应拆为多个对象）、精度退化。

### 5.2 触摸面积 → 橡皮直径

对当前触点做**单调链凸包**，用**鞋带公式**求面积，`diameter = clamp(√area × 1.6, 60, 420)`（屏幕像素，再按缩放折算为世界尺寸）。**跳过** `TextObject`/`FormulaObject`/`ChemicalFormulaObject`（`IsErasable=false`）。

### 5.3 数学求解的数值稳定性

- Brent 求根：先在区间内**采样定位符号变化区间**，再迭代；对不连续点（如 `tan`）做保护。
- Newton-Raphson 方程组：数值雅可比 + 多初值网格 + 随机扰动；解的**去重**用容差聚类。

### 5.4 化学式四角标排版

以元素符号基点为锚，四个角标各带独立偏移与字号（约为正文 0.6 倍），并处理与前后元素的间距累积。**用基线偏移而非独立文本框**，保证缩放后仍对齐。
