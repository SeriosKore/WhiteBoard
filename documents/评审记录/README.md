# 评审记录（非开发基线）

本文件夹存放**语言与技术选型阶段的评审记录**，仅供追溯"当初为什么这么选"，**不作为开发约束**。

> ⚠️ 其中关于**电脑环境与磁盘**的描述（还原卡/系统盘还原、软件盘与盘符、目标机缺 VC++ 可再发行组件、只读介质等）**只是当时用于评审语言选择的背景设定**，已被客户要求移除，**不再适用于开发**。

## 当前有效的开发约束

以 `../白板开发总路线.md` 为准：

| # | 约束 |
|---|---|
| **C1** | **免环境部署**：不装运行时、不装安装包、免管理员、离线可用；不得依赖目标机未预装的组件（含 VC++ 可再发行组件） |
| **C2** | **不写注册表**：应用与插件均不得创建/修改/删除注册表键值，也不得依赖注册表存任何状态 |
| **C3** | **数据自包含**：程序产生的所有数据文件必须位于 **exe 同级目录或其子目录**内（**用户显式保存的画板文件除外**） |
| **C4** | **插件生态开放给第三方**：第三方走沙箱通道，官方走进程内通道 |

| `白板项目_三方案架构与打包设计.md` | C#/WPF、C++/Qt、Rust 三方案的架构与打包结构对比 |
| `白板项目_插件生态与无环境验证.md` | 插件体系与验证流水线详解（部分内容已被 `../计划书_S3_插件生态.md` 取代） |

> 参考时请注意：这些文档中的部署细节与目录规划**以开发文档为准**，此处仅保留结论与论证过程。
