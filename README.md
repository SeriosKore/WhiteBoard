# WhiteBoard

> *Insprited by Seewo Notes, Refer to excalidraw, Based on personal experience,
> I gonna designed a app to satisfy own requirement.*
> —— 项目发起时的初衷（原文保留）

一个给课堂用的**手写白板**：用笔或手指写字、画几何图形、擦改、写文字、翻页，存成 `.wb` 画板文件，也能导出 PNG 交给学生。

当前版本：**[preview v0.1b](https://github.com/SeriosKore/WhiteBoard/releases/tag/preview-v0.1b)**（S1 基础版 · 代码侧已完成）

---

## 四条硬约束

这个项目一开始就是围绕"**能不能在学校电脑上真的跑起来**"设计的，四条约束贯穿全部实现：

| # | 约束 | 落地方式 |
|---|---|---|
| **C1** | **免环境部署** | 自包含单文件夹（约 140 MB），**复制过去双击就能跑**。不装运行时、不要管理员、不联网、**不依赖 VC++ 可再发行组件**（已用 PE 导入表审计验证） |
| **C2** | **不写注册表** | 程序自身状态不落注册表；连"最近文件"都是自己写在 `data\recent.json` 里 |
| **C3** | **数据自包含** | 程序产生的所有数据都在 **exe 同级 `data\`** 内；删掉文件夹即等于卸载干净（用户显式保存/导出的文件除外） |
| **C4** | **插件开放** | 第三方走脚本沙箱通道、官方走进程内通道（S3 实现） |

技术选型：**C# + WPF + .NET 10**（`net10.0-windows`）。
选型理由与"为什么不用 Avalonia / WebView2 / Electron"见 `documents/白板开发总路线.md`——
核心一条：**墨迹延迟**。WPF 走系统合成层，Avalonia 的合成层比它晚 1~5 帧，这正是上一个版本失败的原因。

## 现在能做什么

- **书写**：笔 / 手指 / 鼠标统一处理；压感变宽；**下笔即固定**（已画部分不会再被"平滑优化"移动，ADR-20）
- **图形**：直线 / 矩形 / 椭圆（拖动绘制 + 橡皮筋预览）
- **橡皮**：按覆盖面积**挖掉一块**（不是把一笔切成碎片）；擦空即删；手掌自动当大号橡皮
- **选择**：点选（取最上层）/ 框选 / 圈选 / 多选 / 拖动移动 / 删除 / 置顶置底 / 克隆 / 改笔宽
- **文本**：就地叠加真 `TextBox`，**中文输入法天然可用**；字号三档、粗体、多行
- **多页面**：左侧目录 + 内容裁剪缩略图、翻页、新建/复制/删除页、**跨页搬运对象**（拖动到缩略图）、**拖动缩略图调整页序**
- **文件**：`.wb` 包（ZIP + JSON、**原子写**）、保存/另存为/打开、**自动保存与崩溃恢复**、PNG 导出（当前页/全部页）、**追加导入**、最近文件
- **视图**：滚轮以光标为锚点缩放、中键平移、双指捏合/平移、50 倍无损放大、全屏
- **撤销**：每页独立栈（`Ctrl+Z` 只作用于当前页），页面级操作走状态栏「撤销页面操作」

## 快速开始

### 直接用（推荐）

1. 到 [Releases](https://github.com/SeriosKore/WhiteBoard/releases) 下载最新的 `WhiteBoard_*.zip`
2. 解压出整个文件夹（**不要只复制 exe**，旁边还有运行时与主题文件）
3. 双击 `publish\selfcontained\WhiteBoard.exe`

想确认这台电脑上没问题：双击同目录的 **`验证.cmd`**，看到 **9 行 PASS** 即可。

### 自己构建

需要 **.NET SDK 10**（仅构建需要，运行不需要）：

```powershell
git clone https://github.com/SeriosKore/WhiteBoard.git
cd WhiteBoard
powershell -ExecutionPolicy Bypass -File scripts\verify.ps1
```

这一条命令会：构建 7 个工程 → 跑 **225 项单元测试** → PoC 冒烟 → 自包含发布 → PE 依赖审计 →
三套自检（环境 / 渲染链路 / 文件+页面+文本）→ **画布交互自检** → **拖动交互自检** → 数据目录合规。
**21 项全绿时退出码为 0。**

## 验证方式

这个项目的每一个"能用"都配了**可复核的证据**，不看结论看数字：

| 证据 | 位置 |
|---|---|
| 自动验证报告（21 项） | `artifacts\verify-report.txt` |
| 渲染链路自检（14 项，含"椭圆真的是椭圆""擦除处确实缺像素"） | `artifacts\render-smoke.txt` + `.png` |
| 文件层+页面+文本自检（21 项，含**存读前后逐像素一致**） | `artifacts\file-smoke.txt` |
| 画布交互自检（9 项，**真鼠标真键盘**逐个工具） | `artifacts\ui-tools-test.txt` + `artifacts\ui-tools\*.png` |
| 拖动交互自检（6 项：拖对象 / 中键平移 / 跨页搬运 / 页序拖拽） | `artifacts\ui-drag-test.txt` + `artifacts\ui-drag\*.png` |
| 笔迹稳定性实测（下笔即固定，含新旧行为对比） | `tools\InkStabilityProbe` |

最有说服力的一条：**保存后重新打开，渲染结果逐像素一致（0/1024000）**——
证明"存了再打开还是同一张图"，而不只是"字段没丢"。

## 已知限制（S1 范围）

- 图形**不支持旋转**与手柄缩放（可整体移动）；文本不支持旋转
- 没有图片、数学公式、化学式、右键菜单
- 跨显示器 DPI 变化未处理（只保证**单显示器正确**）
- 4K 界面只保证不错位，未做精细适配
- 插件生态（S3）、i18n 与签名部署（S4）尚未开始

完整清单与优先级见 **[`TODO.md`](TODO.md)**。

## 目录结构
